# Welcome to MarkdownApp

Type on the **left**, see the result on the **right**. This document is untitled —
press **Ctrl+S** to save it somewhere, or **Ctrl+O** to open an existing file.

## Shortcuts

| Action | Keys |
|---|---|
| New / Open / Save / Save As | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| Bold / Italic / Link / Code | Ctrl+B / Ctrl+I / Ctrl+K / Ctrl+` |
| Split / Editor / Preview | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| Zoom in / out / reset | Ctrl+= / Ctrl+- / Ctrl+0 |
| Indent / Outdent | Tab / Shift+Tab |

You can also **drag a `.md` file** onto the window to open it.

## What renders

- *Emphasis*, **strong**, ~~strikethrough~~, and `inline code`
- [Links](https://commonmark.org/help/) open in your browser
- Task lists:
  - [x] Write the spec
  - [ ] Write the next great README

> Blockquotes look like this.

```js
function hello(name) {
  return `Hello, ${name}!`;
}
```
